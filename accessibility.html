Accessibility無障礙

This site is built so that people using screen readers, keyboard navigation or magnification can use it — not as an afterthought, but as part of the design.這個網站是為了讓使用螢幕閱讀器、鍵盤操作或放大工具的人也能使用而建——不是事後補救，而是設計的一部分。

Our commitment我們的承諾

We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.1 at level AA. This site is a student prototype for a university course, so it has not been independently audited — where we know of a limitation, it is listed below rather than hidden.我們以《無障礙網頁內容指引》（WCAG）2.1 AA 級為目標。這個網站是大學課程的學生原型，因此未經獨立審核——我們已知的限制會列在下方，而不是隱藏起來。

Accessibility matters to this project for a practical reason. If our aim is to make technology available to people who are usually left out, the way we present our own work should not exclude anyone either.無障礙對這個專案有實際的理由。如果我們的目標是讓平常被忽略的人也能使用科技，那麼我們呈現自己工作的方式，也不應該排擠任何人。

What is built in已加入的功能

Text size字級調整

The A− and A+ buttons in the header change the whole page between 100% and 140%. The layout is built in relative units, so it reflows instead of clipping. Your choice is remembered on this device.標題列的 A− 與 A+ 按鈕，可以把整個頁面在 100% 至 140% 之間調整。版面以相對單位建立，因此會重新排版，而不是被裁切。你的選擇會在此裝置上保留。

Light and dark themes深色與淺色主題

The sun and moon button switches theme, and the page follows your operating system setting until you choose. Both themes keep text contrast at 4.5:1 or better.太陽與月亮按鈕可切換主題；在你自行選擇之前，頁面會跟隨作業系統設定。兩個主題的文字對比度都維持在 4.5:1 或以上。

Two languages雙語

Every page is available in English and Traditional Chinese. The page language attribute changes with the content, so a screen reader uses the right pronunciation rules.每一頁都提供英文及繁體中文版本。頁面的語言標記會隨內容改變，螢幕閱讀器因此會使用正確的發音規則。

Screen readers螢幕閱讀器

Pages use landmarks, one main heading, a logical heading order, and a skip link as the first focusable item. Decorative graphics are hidden from assistive technology; nothing important is described only by an image.頁面使用地標區域、單一主標題、合乎層級的標題順序，並以「跳至主要內容」作為第一個可聚焦項目。裝飾性圖形不會被輔助技術讀出；重要資訊不會只以圖像表達。

Keyboard only純鍵盤操作

Every control works with Tab, Enter and Space, focus is always visible, and the mobile menu closes with Escape. There are no keyboard traps and nothing is triggered automatically by hovering.所有控制項都可以用 Tab、Enter 及空格鍵操作，焦點永遠可見，手機版選單可按 Escape 關閉。沒有鍵盤陷阱，也沒有隻靠滑鼠停留才觸發的內容。

Motion and forms動態效果與表格

Animation is minimal and respects the reduced-motion setting. Form fields have visible labels, hints, and error messages tied to the field, and errors are announced and focused.動態效果極少，並尊重系統的「減少動態」設定。表格欄位有可見標籤、提示，以及與欄位連結的錯誤訊息；錯誤會被讀出並把焦點移到出錯的欄位。

Using the controls如何使用這些控制

The three controls sit under the main menu on every page.三個控制項位於每一頁的主選單下方。

  • Language — the EN and Chinese buttons. The current language is marked as pressed.語言——EN 與「中文」按鈕。目前語言會標示為已按下。
  • Text size — A− makes text smaller, A+ makes it larger. The current percentage is shown between them.字級——A− 縮小文字，A+ 放大文字，中間會顯示目前的百分比。
  • Theme — the sun or moon button switches between light and dark.主題——太陽或月亮按鈕，在淺色與深色之間切換。
  • All three choices are saved in this browser only. Clearing site data resets them.三個選擇只會儲存在這個瀏覽器。清除網站資料即會重設。

Known limitations已知限制

  • The site has not been tested with every screen reader and browser combination. We have tested with Windows Narrator, NVDA and keyboard-only navigation.網站未經所有螢幕閱讀器與瀏覽器組合測試。我們以 Windows 朗讀程式、NVDA 及純鍵盤操作測試過。
  • The contact form is a prototype: it validates input but does not send or store it.聯絡表格是原型：會檢查輸入，但不會送出或儲存。
  • There is no audio or video content, so no captions are needed yet.目前沒有音訊或影片內容，因此暫無字幕需要。
  • A few technical terms (filament, additive manufacturing) appear in English inside the Chinese text, because there is no settled Hong Kong translation.少數技術詞彙（線材、增材製造）在中文版中會保留英文，因為香港尚未有統一譯法。

Tell us what does not work告訴我們哪裡不能用

If something on this site blocks you — a control you cannot reach, text you cannot read, a page that does not make sense with a screen reader — please write to如果這個網站有任何地方阻礙你——無法到達的控制項、讀不到的文字、用螢幕閱讀器讀起來不合理的頁面——請電郵 accessibility@3rdcompany.hk. We will fix it and say what we changed.我們會修正，並說明改了什麼。
